# sunnyvaledispatch.com

Static landing site for the Sunnyvale Dispatch newsletter (GitHub Pages). Generated by `site/dispatch/build.py sunnyvale` in the ai-ops repo. Edit there, rebuild, push here. The signup form posts to the n8n webhook `sunnyvale-dispatch-signup`, which creates the beehiiv subscription with custom fields; beehiiv → n8n → Follow Up Boss.
